# Что проверяется

Прошлый прогон показал, что по времени предел держится, а по энергии
ответа не дал: десяти секунд работы и двух кругов мало, мощность от круга
к кругу скакала в разы. Этот прогон — только про энергию:

- **9 стратегий:** восемь самых дорогих по энергии в прошлом прогоне и
  «топливо»;
- **три круга по 20 с работы и 15 с покоя** — как в шаге 8б, где энергия
  мерилась.

**Правило разбора объявлено до прогона:**

- мощность стратегии ΔP — среднее второго и третьего кругов (первый —
  разгон);
- ΔP надёжна, если она больше своего разброса между этими кругами;
- энергия контура = ΔP × среднее время контура;
- предел по энергии **держится**, если у всех девяти стратегий энергия
  не больше 97 мДж; **не держится**, если хоть у одной больше; если хоть
  у одной ΔP ненадёжна — **нельзя сказать**.

Правило проверено на файле прогона шага 8б (три круга по 20 с): там оно
дало энергию всех семи стратегий.

# Перед началом

- Телефон **снят с зарядки**.
- Заряд — **не меньше 40 %**.
- Телефон **прохладный**.
- Около **17 минут** телефон будет занят. Другие приложения лучше
  закрыть.

# Шаги

1. **Скачайте** `stend8ve.apk` из чата и **откройте** — MIUI предложит
   **обновить** «Стенд шага 8». Прежние файлы замеров останутся.
2. **Откройте стенд** и нажмите **«Начать»** внизу слева.
3. **Смотрите на верхние строки:** «Шаг … из 56, круг …» и «Идёт:
   работа «…»». Если стенд стоит, там же написано почему: не снят с
   зарядки, мало заряда, батарея горячая, приложение свёрнуто.
4. **Не сворачивайте стенд,** пока идёт замер.
5. Когда наверху появится **«Готово: все замеры сделаны»**, нажмите
   **«Поделиться»** и пришлите файл **`shag8ve_….txt`** сюда.

# Если что-то пошло не так

Пришлите снимок экрана и файл замеров, даже неполный.
