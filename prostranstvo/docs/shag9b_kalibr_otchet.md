# Итог

**Калибровка на телефоне — «да» по всем шести вердиктам стенда**, каждый
сверен с сырыми числами файла (урок 31). Законы журналов К6 — 41 в каждом
из трёх сценариев, нарушений 0. Энергия — с поправкой ×2 на двухбаночную
батарею (решение владельца, принято до К5): проверка единиц — «да»
(0,942), К5 по энергии — «да».

Пара калибровки: Qwen2.5-1.5B-Instruct Q4_K_M, быстрая программа модели
(dotprod, i8mm), 4 потока на выдачу и 8 на чтение, A = 256 байт, бюджет
контура 625. Телефон — iQOO Neo 10 (vivo I2405), Android 16.

Файлы: `experiments/results/shag9b_kalibr_phone/` (как прислано),
разбор — `shag9b_kalibr_phone_razbor.json` (с поправкой) и
`shag9b_kalibr_phone_razbor_bez_popravki.json`.

# 4. Условия прогона

- **Телефон лежал на хладоэлементе** (из морозилки, в полотенце). Батарея:
  в К5 — 23,6 → 39,0 °C, в К6 — 34,5–39,5 °C. Без охлаждения худший
  контур за 39 минут доводил батарею до 45 °C, и сторож его прерывал
  (первый заход К5).
- Без зарядки: К5 — 100 → 71 %, К6 — 71 → 44 %.
- Пять запусков. Два захода К5 прерваны (сторож на 45 °C; остановка
  владельцем из-за застывшего экрана — промах № 51), два запуска
  отказались начинать из-за тёплой батареи; стенд каждый раз продолжал с
  незаконченного этапа. Подробно — спецификация, §19.

# 5. Энергия: поправка ×2

Датчики телефона дают половину мощности: у двухбаночной батареи система
отдаёт напряжение одной банки (4,46 В при полном заряде) или ток одной
ветви. Без поправки ∫U·I = 13,40 Вт·ч против 28,44 Вт·ч по убыли заряда
(отношение 0,471, «нельзя сказать»). Владелец принял поправку ×2 до того,
как были данные К5. С ней — 0,942 по трём отрезкам без зарядки; на отрезке
К5–К6 (124 минуты, −56 %), который в выводе поправки не участвовал, — 0,93.

Вердикт «К5 по энергии» от поправки не зависит: множитель одинаково входит
и в энергию контура, и в предел₂. От поправки зависят абсолютные числа
(джоули, ватты).

# 6. Чего это не доказывает

- **Телефон был охлаждён.** Предел верен для охлаждённого телефона; при
  44–45 °C время вопроса не мерено (журнал горячего захода не сохранился —
  промах № 53).
- **Поправка ×2 для К2–К3 не независима** — она выведена из их же данных;
  для К5 объявлена заранее и подтверждена отрезком К5–К6.
- **Один телефон, одна прошивка** (Android 16).
- **Аудит вызовов системы в К6 на телефоне не проверен** — прибора нет;
  законы журналов проверены на сервере.
- **Время вопроса в ходе — с точностью до опроса** (2 с); время контура и
  предел — по часам стенда.
- Из прежних шагов: время ответа модели как побочный канал не закрыто;
  предел верен только для наблюдавшихся состояний телефона.
