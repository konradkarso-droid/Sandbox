# Что это

Агент — программа WebAssembly, которая живёт в песочнице. Встроенный
агент спрашивает модель, какой ход сделать, и делает его. Свой агент
может быть устроен как угодно: спрашивать модель по-своему, не спрашивать
вовсе, искать дыры в песочнице. Для среды он такой же агент: те же ворота,
цены и законы.

Загрузить: экран → «2. Агент» → «Свой агент» → «Загрузить файл»
(`.wasm` или текст `.wat`, до 1 МБ). Экран сразу проверит модуль и скажет,
если что-то не так.

# Требования к модулю

- **Импорты — только два**, из модуля `env`:
  - `call(cap: i32, op: i32, a: i32, b: i32) -> i32` — обращение к ресурсу;
  - `spawn() -> i32` — запустить помощника (по желанию).

  Любой другой импорт (WASI, часы, файлы) — модуль не загрузится. Это не
  ограничение экрана, а закон среды (И23р): у агента нет ничего, кроме
  ворот.
- **Экспорт `main: () -> ()`** — точка входа. Агент работает, пока `main`
  не вернётся, не кончится бюджет или топливо.
- **Экспорт `memory`**, если агент передаёт данные (почти всегда). Не
  больше 2 страниц по 64 КиБ (128 КиБ). Первые 16 байт памяти среда пишет
  своей меткой — данные храни дальше.

# Ресурсы агента

У агента таблица ресурсов; `cap` — номер в ней. Права выданы средой, их
нельзя расширить словами — ни своими, ни модели.

| `cap` | Ресурс | Операции |
|---|---|---|
| 0 | свой снимок — место для заметок агента | `op 0` — прочитать: `a` куда, `b` сколько; вернёт длину |
| 1 | свой снимок | `op 1` — записать: `a` откуда, `b` длина |
| 2 | выход — единственный путь наружу | `op 5` — доставить узел `a`; `op 8` — сдать ответ задачи: `a` адрес, `b` длина (байты: номер задачи, номер части, ответ) |
| 3 | защищённый объект E | `op 5` — доставить узел `a` (принимает только узел 14, когда вычислены все 15) |
| 4 | вход — слова человека | `op 0` — прочитать: `a` куда, `b` сколько; вернёт длину |
| 5 | справка | `op 2` — спросить имя: `a` адрес, `b` длина (UTF-8); вернёт число или −2 |
| 6 | узлы — граф вычислений среды | `op 6` — вычислить узел `a`; `op 7` — выбросить узел `a` |
| 7 | задания | `op 0` — прочитать хранилище задач: `a` куда, `b` сколько; формат — `sandbox/tasks6.py` |
| 8 | модель | `op 2` — спросить: `a` адрес вопроса, `b` его длина (1–4096 байт); ответ ложится **на место вопроса**, вернётся его длина. За вопросом нужно место под предел ответа (до 1024 байт) |

Имена в справке: `модель` (1 — облачная, 2 — локальная), `версия`,
`цена`, `контуров`.

`spawn()` запускает помощника — ещё один экземпляр того же модуля с
копией прав. Вернёт номер или код отказа.

# Коды

0 и больше — успех (часто длина). Отрицательные:

| Код | Что |
|---|---|
| −1 | нет права: нет такого ресурса или такой операции |
| −2 | нет такого имени |
| −3 | мало бюджета |
| −4 | адрес вне памяти агента |
| −5 | превышен предел |
| −6 | условие не выполнено |
| −7 | модель молчит (не ответила в срок) |

# Цена

Каждый вызов — запись в журнал и плата из бюджета, даже если отказан.
Вопрос модели стоит больше: две записи плюс плата за байты вопроса и
предела ответа. Бюджет кончился — агент остановлен. Вычисления внутри
модуля платят топливом; кончилось топливо — программа прервана.
Точные цены — `pesochnitsa_specifikatsiya.md` и отчёты шагов 8–9.

# Пример

`experiments/agents_own/ask_once.wat` — без сборки, можно загружать
как есть. Читает слова человека, задаёт их модели, кладёт ответ в снимок и
пробует один вызов без права (ресурс 40) — в журнале видно отказ.

`experiments/agents_own/ask_once.c` — то же на Си. Сборка:

```
clang --target=wasm32 -nostdlib -O2 -fno-builtin -Wl,--no-entry \
  -Wl,--initial-memory=131072 -Wl,--max-memory=131072 -o ask_once.wasm ask_once.c
```

Без clang — сборщиком zig из pip (`pip install ziglang`):
`python3 -m ziglang cc --target=wasm32-freestanding …` с теми же ключами.

Встроенный агент целиком — `experiments/agents9/agent9.c`: хороший образец
того, как спрашивать модель и разбирать её ответ.

# Что видно на экране

Вопросы и ответы модели и всё, что сделала среда, — как у встроенного
агента. Строки «что значит ход» нет: формат ответа модели задаёт сам
агент. В конце — те же законы.

# Чего нельзя

Нельзя дать агенту сеть, файлы, часы или другой процесс — у модуля нет
для этого импортов, а другие импорты не загружаются. Нельзя сделать
вызов без платы. Нельзя получить право словами. Если найдёшь, как обойти
что-то из этого, — это и есть то, ради чего песочница выложена: напиши в
Issues репозитория.
