# Заметки ко второй реализации исполнителя

Исполнитель — `executor/` (Rust, wasmi 2.0). Модули: `canon` (канонический
JSON), `journal`, `graph`, `tasks` (SplitMix64, хранилище задач, проверка),
`core` (объекты, ворота, фиксация, узлы, сдача ответа), `engine` (wasmi:
загрузка, запуск, помощники), `setup` (настройки, new/recover/dump),
`main` (протокол).

## Неоднозначности контракта и как решены

- **Начало счётчика номеров фиксации.** Контракт: «n растёт на 1 при каждой
  попытке» и «после восстановления — наибольший n плюс 1». Принято: первый
  номер — `i-0`; поле `fixno` выгрузки — число уже выданных номеров (следующий
  номер). Тогда после восстановления `fixno` = max n + 1 тем же правилом.
  Судья на конкретные значения не смотрит, только на уникальность.
- **Файлы получателей** (`выход{i}.jsonl`, `E{i}.jsonl`) создаются пустыми
  при `new`. Контракт этого не требует, но обвязка (`harness._project1`)
  читает `выход1.jsonl` до первой фиксации и падает, если файла нет.
- **Право не совпало с операцией** (например, чтение объекта с правом «зап»)
  в обычных операциях — `-1`, после проверок памяти (-4) и номера (-1).
- **Проваленная загрузка агента** (ловушка или отказ движка): запись агента
  не попадает в выгрузку (иначе его таблица оказалась бы в выгрузке без
  записи «начало»); повторная загрузка допустима. Помощники, успевшие
  родиться в стартовой функции, остаются. Неудавшийся помощник (ловушка
  старта) в выгрузку не попадает и в предел экземпляров не засчитывается.
- **Ошибка движка при создании экземпляра, не ловушка** (например, память
  больше предела): при `load` — исход «отклонён», запись «загрузка
  отклонена»; при `spawn` — `-5` и отказ −5.
- **Импорты** проверяются до создания экземпляра сами (имя, вид, подпись), не
  полагаясь на сообщения компоновщика.
- **Неизвестные имена точек сбоя** и неверные типы/диапазоны настроек —
  отказ команды. `task_rng = "python"` отвергается отказом (разрешено
  контрактом). Диапазоны: levels 1…20; число частей задач ≤ 255; прочее
  разумные границы (см. `setup::in_range`).
- **Счёт точек «запись … оборвана»** идёт при каждом проходе записи, в том
  числе «запись доставки оборвана» только когда строка действительно
  пишется (пара уже есть — прохода нет; при обычной работе такого не бывает).
- **`say`** обрезает по байтам; возможен разрыв последнего знака UTF-8.

## Различия, которые дал движок

- Топливо — единицы wasmi (около 1 за инструкцию); предел 3 000 000 на
  контур на всё время жизни хранилища, а не на один `run`.
- Глубина стека — по умолчанию wasmi; «рекурсия» даёт «стек исчерпан».
- Лимит памяти — `StoreLimits`: рост выше 2 страниц возвращает −1 без
  ловушки; изначально большая память не создаётся (ошибка не-ловушка).

## Не сделано

- Порчи (контракт их не требует), прибор аудита (`audit` → `[]`).
