# Что это

Песочница, в которой живёт агент: он спрашивает модель, что делать, и
делает ходы — читает задания, решает задачи, вычисляет узлы, пробует
выбраться наружу. У каждого хода есть цена, бюджет конечен, всё ложится в
журнал. Выхода наружу нет не по запрету словами, а по устройству среды. В
конце прогона наблюдатели проверяют по журналу законы среды, и экран
показывает, держатся ли они.

Модель можно взять **местную** (файл GGUF на этом компьютере — сомкнутый
контур) или **облачную** по ключу (разомкнутый контур). Устройство и
гарантии — `docs/pesochnitsa_specifikatsiya.md`.

# Что нужно

- Linux (Ubuntu, Debian, Fedora, Arch …) на x86_64 или aarch64. В Windows
  10/11 — через WSL2 (`wsl --install`, затем всё внутри Ubuntu). macOS не
  поддерживается.
- Python 3.11 или новее и git. В Debian и Ubuntu ещё `python3-venv`:
  `sudo apt install git python3-venv`.
- Около 300 МБ места; модели — отдельно (0,5–1 ГБ каждая).

# Запуск

```
git clone -b prostranstvo https://github.com/konradkarso-droid/agent-mobile prostranstvo
cd prostranstvo/prostranstvo
python3 start.py
```

Первый запуск заводит своё окружение Python в папке `.venv` (системный
Python не трогается), ставит wasmtime и собирает агента — системным
clang, а если его нет, сборщиком zig из pip. Это минута-две. Потом
открывается браузер. Если не открылся — ссылка напечатана в терминале
(вида `http://127.0.0.1:8737/?t=…`; без метки `t` экран не откроется).

Остановить экран — Ctrl+C в терминале.

# Первый прогон — демо

Контур «Сомкнутый», модель «Демо — без модели», слова любые — «Пуск».
Демо-модель отвечает заранее записанными ходами, среди них попытки
выбраться: справка про «снаружи», сырые вызовы ворот на чужие номера,
доставка в защищённый объект раньше времени. Прогон идёт секунды. Видно:

- **ходы агента** — фиолетовым то, что сказала модель; под ним — что
  сделали ворота (красным — отказы с кодом и причиной);
- **счётчики** — бюджет и остаток, вопросы модели, сколько байт ушло к
  модели, отказы ворот по кодам;
- **итог** — законы, сгруппированные по смыслу: «выхода наружу нет»,
  «контуры не сообщаются», «права не берутся из слов», «всё оплачено и
  записано» и т. д. Нажми на группу — откроются сами законы.

Нажми на ход — откроются вопрос модели целиком и её ответ.

# Сомкнутый контур с настоящей моделью

1. Поставить движок (один раз, сборка около 10 минут; нужны cmake и
   компилятор C++ — в Ubuntu `sudo apt install cmake build-essential`):
   `python3 start.py --local`
2. На экране — «Скачать Qwen2.5 0.5B» или «1.5B»: файл проверяется по
   опубликованному хешу. Свой файл GGUF можно просто положить в папку
   `models` рядом со `start.py`.
3. Выбрать модель, написать слова агенту или взять готовые («честный»,
   «наружу», «разрешение», «соседу» …), «Пуск».

На процессоре 0,5B отвечает за секунды, 7B — за минуту и больше на
вопрос; срок ответа — в «Подробно» (по умолчанию 300 с).

Сеть у песочницы в сомкнутом контуре отнята системой: на экране сказано
«печать сети». Если система печать не принимает, сеть у процесса модели
отнимается пустым сетевым пространством; если нет и его — сомкнутый
контур не запустится (и это правильно).

# Разомкнутый контур — облачная модель

1. «Разомкнутый», поставщик из списка (OpenRouter, Anthropic, OpenAI,
   DeepSeek, Groq, Mistral, Gemini; Ollama или LM Studio на своей
   машине; любой другой с протоколом OpenAI — «Другой»).
2. Имя модели — руками или кнопкой «Список» (спросит у поставщика).
3. Ключ — в поле. Он живёт в памяти программы до конца прогона и никуда
   не пишется. Можно не вводить, а задать до запуска переменной
   окружения: `OPENROUTER_API_KEY=… python3 start.py` (имя переменной
   показано под полем).
4. «Проверить связь» — короткий вопрос мимо песочницы: неверный ключ или
   имя модели видны сразу.
5. «Пуск».

Каждый вопрос агента уходит поставщику — это второй разрешённый вывод
среды. Он оплачен из бюджета и записан в журнал до отправки. Деньги
поставщика — отдельно: в итоге показаны токены, которые насчитал он.
Один прогон — до ~45 вопросов на агента, каждый до 4 КБ.

Если облако не ответило (нет денег на счёте, лимит, сбой) — агент
получает «модель молчит» (−7), на экране — причина от поставщика.

# Что в «Подробно»

| Поле | Что |
|---|---|
| бюджет агента | сколько единиц на весь прогон (625 — как в опытах) |
| предел ответа | сколько байт ответа модели попадает агенту (до 1024) |
| срок ответа | сколько ждать модель; 0 — 300 с местной, 90 с облачной |
| номер набора задач | какие задачи выдаст среда |
| второй агент | «молчит» — сосед есть, но не ходит; «такой же» — со своей моделью (вдвое дольше и дороже) |
| токенов на ответ облака | для моделей с рассуждением, которым мало половины предела |

# Где файлы

Каждый прогон — папка `runs/ДАТА_ВРЕМЯ/`: журнал среды
(`ispolnitel/run00001/journal5.jsonl`), получатели, итоги (`itog.json`).
Кнопка «Скачать журнал и итоги (zip)» — то же одним файлом. Ключа там нет.

# Без экрана

`python3 start.py --check` — демо-прогон и вердикт законов в терминал.
Годится, чтобы проверить установку.

# Если что-то не так

| Что видно | Что делать |
|---|---|
| «Не вышло завести окружение» | `sudo apt install python3-venv` |
| «сомкнутый контур здесь недоступен» | система не умеет отнять сеть у процесса (не Linux или старое ядро) — разомкнутый работает |
| «нужен движок местной модели» | `python3 start.py --local` |
| облако: «ключ не принят (401)» | проверь ключ |
| облако: «на счёте нет денег (402)» | пополни счёт у поставщика или возьми бесплатную модель |
| облако: «поставщик просит подождать (429)» | лимит запросов; подожди или возьми другую модель |
| модель отвечает, но «не ход» | модель не держит формат ходов — это её свойство; возьми модель сильнее |
| экран «Открой ссылку, которую напечатал start.py» | открой ссылку из терминала целиком, с `?t=…` |

Остальное — `docs/pesochnitsa_specifikatsiya.md`, §8 «Чего песочница не
умеет».
