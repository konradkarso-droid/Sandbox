# Пространство — исследовательский стенд «Теории среды»

Стенд для проверки «Теории среды» — причинно-ресурсной вычислительной
среды. Здесь проверяется, чьё наблюдаемое свойство: предполагаемого
пространства, выбранной модели или конкретной реализации.

## Песочница

`python3 start.py` — экран в браузере на двух языках: модель (любой файл
GGUF внутри песочницы без сети или облачная по адресу и ключу), что
проверить, ходы агента с объяснением каждого, законы в конце. Как
пользоваться — `docs/pesochnitsa_kak_zapustit.md` (по-английски —
`docs/sandbox_guide_en.md`); устройство, гарантии и чего она не умеет —
`docs/pesochnitsa_specifikatsiya.md`. `python3 start.py --check` —
проверка установки без модели и без экрана.

```
start.py                       запуск: своё окружение .venv, wasmtime, сборка агента (clang или zig из pip)
app/
  runner.py                    один прогон: печать сети, процесс модели или передатчик, журнал по ходу, законы
  texts.py                     сценарии и законы простыми словами, на двух языках
  seal.py                      печать сети: seccomp на процесс исполнителя, проверка строгой пробой §18
  cloud.py                     облачная модель: протоколы OpenAI и Anthropic
  bridge.py                    связь разомкнутого контура: местный канал ↔ облако (ключ только здесь)
  server.py, ui/index.html     экран: только 127.0.0.1, метка в ссылке; цвета приложения агента
  install_check.json           записанные ходы для проверки установки (serve.py --script)
experiments/agents9/agent9.c   встроенный агент; ключ сборки LANG_EN — правила по-английски
experiments/agents_own/        пример своего агента (ask_once.wat — без сборки, ask_once.c)
model9/serve.py --relay        передатчик: процесс модели разомкнутого контура без своей сети
```

## Как запустить

Нужен Python 3.11+, PyYAML и pytest; для шагов 5–6 — wasmtime 50.0.1; для шага 6 — clang с целью wasm32;
для шага 7 — Rust (cargo) и strace; для шага 8 — JDK, Android SDK (build-tools 34, platform 34) и NDK r27.
Для шага 9 — `unshare` (процесс модели без сети); для живой модели — llama-cpp-python и файл модели GGUF.
Ход «спросить модель» — `sandbox/executor5b.py` (`_ask`), переходник — `sandbox/model9.py`, процесс модели —
`model9/serve.py`, мир с моделью — `core/mir9.py`, приборы — `experiments/strace9.py`, `experiments/measure9.py`; цикл агента — `experiments/agents9/agent9.c`;
пилот и проба модели — `experiments/pilot9.py`, `experiments/probe9.py`. Ход во второй реализации проверяют
набор `--suite 9` и `--suite attempts9` обвязки судьи (`rust7/judge/harness.py`) и `run_shag9_vtoraya.py`.
Шаг 9б (режим 2, «модель на устройстве», контракт §18): условие режима — в `sandbox/process5.py`; способ «без сети»
(`--model-net netns|probe`, строгая проба, процесс модели умирает с исполнителем) — `sandbox/model9.py`; у судьи —
`--suite net` (закон «К18», подменная `socket()` `rust7/judge/model9/nosock.c`), `--suite 9 --model-mode 2
[--model-net probe]`; прибор токенов и окна модели — `experiments/measure9b.py`.
Родная программа модели (C++ поверх llama.cpp из пакета llama-cpp-python 0.3.37, для сервера и телефона) —
`model9/native/serve9.cpp`, сборка — `model9/native/build.py` (нужны cmake, а для телефона — NDK r27);
сверка с `serve.py` и strace — `experiments/native9.py`; с ней на месте `serve.py` — `run_shag9b_native.py`
и ключ `--serve` обвязки судьи. Тесты родной программы идут, если путь к ней задан в переменной `SERVE9`.
Малый стенд шага 9б (пункт 5, приложение без разрешений) — `phone9/`: ведущий `Stand9` одинаков на телефоне и
на сервере; программы-агенты — `phone9/assets9.py`; сборка APK — `phone9/build.sh`; проверка стенда порчей —
`phone9/check9.py`; инструкция для телефона — `docs/shag9b_stend_kak_zapustit.md`.

## Правило чтения результатов

- **«Доказано в модели»** — только для проверенных параметров и только для
  модели.
- **«Наблюдалось»** — прогоны без полноты.
- **Свойством пространства** результат становится лишь после воспроизведения
  в независимой реализации (концепция, часть I). Для шагов 5б и 6 это
  сделано в шаге 7 — с оговоркой: контракт и судья у обеих реализаций общие.
