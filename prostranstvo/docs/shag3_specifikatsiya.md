# 1. Что проверяет шаг и чего не проверяет

**Проверяет** впервые главный пробел программы — звено Л4 и гипотезу Г:
дороже ли бюджета любой путь к защищённому эффекту, если путь к нему
существует. Вместе с ним:

- Ц3–Ц6;
- полезность в форме П1 — в узкой форме, §3;
- опыты О4 (серия квантования), О5 (обходы), О7 (полный поиск);
- варианты M3 и абляции M3а и M3б.

**Делается на уровне модели.** Точный поиск наименьшей работы по всем
состояниям памяти. Перенос на реализацию (env) — после того, как модель
даст ответ.

**Не проверяет:**

- эталоны Э1 и Э2 из О4;
- физическую цену шага (О9);
- живого агента.

**Решения пользователя, на которых стоит шаг:**

1. **Уровень** — накопленное продвижение, выведенное из журнала как
   провенанс. Уровень = число шагов, впервые выполненных и записанных.
   История может только проверять уровень или уменьшать шаг, но не
   увеличивать.
2. **Зависимость** — маленький граф с «камешками». Простая цепочка — как
   нижняя планка для сравнения; граф, устойчивый по глубине, — позже.
3. **Два получателя.**
   - «Выход полезной работы» принимает результаты мелких уровней.
   - «Защищённый объект» принимает только результат последнего шага, и
     только если уровень K подтверждён журналом.

# 2. Мир M3

**Продвижение идёт уровнями k = 0 … K−1.** На уровне k ровно 2ᵏ шагов: с
каждым уровнем шаг вдвое мельче (q(k) = q₀·2⁻ᵏ, концепция §19). Всего шагов
N = 2ᴷ − 1. Шаги пронумерованы в порядке продвижения: 0, 1, 2, …

**Шаг — это вычисление узла графа.** Вычислить узел можно, только если
результаты всех его предков сейчас в памяти. Вычисление стоит 1 единицу
работы — объявленная цена, §6.

**Первое вычисление узлов — строго по порядку.** Уровень — это число
узлов, вычисленных впервые; он выводится из журнала. Пересчитать уже
вычисленный узел можно в любом порядке, если предки в памяти. Пересчёт
тоже стоит 1.

**Память:**

- одновременно в памяти не больше M результатов во всех хранилищах
  вместе — у всех помощников, в снимках, где угодно;
- выбросить результат можно бесплатно;
- выброшенный результат при нужде пересчитывается.

**Формы зависимостей** — все малые графы с «камешками»:

| Граф | Предки шага (k, i) | Смысл |
|---|---|---|
| **M3ц** — уточнение со сквозной цепочкой | предыдущий шаг по порядку и крупный шаг (k−1, ⌊i/2⌋), который он уточняет | каждый шаг опирается на всю историю |
| **M3т** — уточнение по трафарету | два соседних крупных шага: (k−1, ⌊i/2⌋) и (k−1, ⌊i/2⌋+1) | мелкий шаг вычисляется из двух крупных, как сетка уточняется по соседям |
| **M3а** — измельчение без зависимостей | только предыдущий шаг | абляция: число шагов то же, памяти не нужно |
| **M3б** — зависимости без измельчения | трафарет, но на каждом уровне 2 шага | абляция: зависимости есть, шаг не мельчает |

# 3. Цели и два получателя

**Защищённый эффект E.** Доставить на защищённый объект результат
последнего шага (сток графа). Условия: уровень по журналу равен N, и
результат стока в памяти.

**Полезные задачи.** Выдать на выход результат последнего шага уровня 1
(задача П1-1) и уровня 2 (задача П1-2). Это узкая форма полезности: мелкое
продвижение по тому же графу. Отдельные задачи (сортировка, таблица) — шаг
4.

**Что считается:**

- W_E — наименьшая работа до E;
- W_П — наименьшая работа до полезной задачи.

**Окно бюджета** — значения B, при которых полезные задачи выполнимы, а E
нет: W_П-2 ≤ B < W_E.

**Если E недостижим ни при каком бюджете** (памяти меньше нужного), это
**замкнутость**, а не ресурсная граница (концепция §6). Считается и
пишется отдельно.

# 5. Порчи и законные сокращения — разные вещи

**Порча** — ошибка учёта. Её обязан поймать закон.

**Законное сокращение** — свойство среды, которое агент вправе
использовать: найденный более быстрый путь «пересматривает нижнюю
границу; его нельзя запрещать задним числом» (концепция, О5). Законы на
нём молчат. Если сокращение роняет W_E ниже B, это **опровержение** Г для
такой среды, а не ошибка исполнителя.

| Код | Что | Вид | Должно сработать |
|---|---|---|---|
| Ж1 | уровень — поле, его можно объявить | порча | И11, И14 |
| Ж2 | у каждого из двух помощников своя память M | порча | И12 |
| Ж3 | снимок не считается в памяти | порча | И12 |
| Ж4 | «не было пересчётов» разрешает новый шаг без одного предка (история увеличивает шаг) | порча | И13 |
| Ж5 | результат можно бесплатно поднять из журнала | порча | И13, И15 |
| Ж6 | выброс результата возвращает работу | порча | И16 |
| С1 | у узла есть прямая формула: вычисляется без предков | законное | — |
| С2 | сжатие: в одну ячейку памяти входят два результата | законное | — |
| С3 | без провенанса: E требует только результат стока, не уровень | абляция решения 1 | — |

# 6. Откуда берётся каждая стоимость

| Что | Откуда | Чем НЕ является |
|---|---|---|
| **Шаг = вычисление узла = 1** | объявленная цена | физической работой; калибровка — О9 |
| **Число шагов N = 2ᴷ − 1** | правило измельчения; держится провенансом: каждый шаг выполнен и записан | возникающей трудностью — это объявленное число |
| **Пересчёт сверх N** | вынужден пределом памяти M и формой графа; найден точным поиском | — |

Различение «объявлено» и «вынуждено» — главный вопрос шага. Ответ на
него дают абляции M3а и M3б.

# 7. Метод

- **Поиск в ширину с весами 0 и 1** по состояниям «что в памяти + уровень».
  Вычисление стоит 1, выброс — 0. Первое достижение цели и есть наименьшая
  работа.
- **Законы проверяются на каждом переходе.**
- **Перекрёстная проверка.** Вторая, независимо написанная реализация
  поиска (обычный алгоритм Дейкстры по множествам) на малых K обязана дать
  те же числа.

**Размеры:** K = 3…5, M = 2…7. Граница: при K = 5 и M = 7 перебор доходит
до примерно 10 млн состояний; больше машина не держит.

# 8. Чего модель не умеет

- **Цена вычисления объявлена (1)**, а не измерена.
- **Узел абстрактен.** Нижние границы держатся, только если у функции узла
  нет прямой формулы и её результат несжимаем — допущение «случайного
  оракула» из концепции §21. Сокращения С1 и С2 показывают, что будет без
  него.
- **Малые графы.** Асимптотика теории (размен «время × память») здесь не
  видна; видны точные числа для N ≤ 31.
- **Помощники не моделируются отдельно.** Работа складывается, память
  общая, поэтому любая стратегия нескольких помощников равна некоторому
  порядку одного. Иначе — порча Ж2.
- **Полезность — только мелкое продвижение по тому же графу.**
